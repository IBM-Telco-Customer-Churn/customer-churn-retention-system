# 📊 Customer Churn Intelligence & Retention System

Welcome to the **Customer Churn Intelligence & Retention System** repository. This project is built using the IBM Telco Customer Churn dataset to predict customer churn, perform SQL analytics, and build an interactive retention dashboard.

---

## 📁 Repository Structure & Data Directory

| File / Folder | Type | Description |
| :--- | :--- | :--- |
| `telco.csv.zip` | **Raw Data** | The original IBM Telco Customer Churn dataset (Compressed CSV). |
| `README.md` | Documentation | Project overview and team guidelines. |

---

## 🚀 Getting Started for Team Members

If you are working on the analysis, SQL, or ML notebooks:

1. **Download Raw Data:** Unzip `telco.csv.zip` locally into your working directory.
2. **Data Pipeline:** Do not overwrite `telco.csv.zip`. Any cleaned or transformed data should be saved in a new `data/processed/` folder.
